📖 Step-by-Step Setup Guide (বাংলায় নির্দেশিকা)

Option 1: Brevo (Sendinblue) ফ্রিতে সেটআপ করার নিয়ম (২ মিনিট):
  1. brevo.com-এ গিয়ে ফ্রি একাউন্ট সাইন-আপ করুন।
  2. লগইন করে উপরের ডানপাশে প্রোফাইলে ক্লিক করে SMTP & API মেনুতে যান।
  3. Generate a new API key-এ ক্লিক করে কি (Key) কপি করুন এবং উপরের বক্সে পেস্ট করুন।
  4. Senders & IP মেনুতে আপনার ব্যক্তিগত Gmail টি ভেরিফাই করে দিন।
Option 2: Gmail App Password তৈরি করার নিয়ম (১ মিনিট):
  1. আপনার Google Account-এর Security সেটিংসে যান (myaccount.google.com/security)।
  2. 2-Step Verification চালু থাকতে হবে।
  3. সার্চ বারে লিখুন "App Passwords" (বা 2-Step Verification এর ভেতর নিচে যান)।
  4. App name এ "DNS Store" লিখে Create চাপুন। ১৬ ডিজিটের পাসওয়ার্ডটি কপি করে উপরের বক্সে পেস্ট করুন।
