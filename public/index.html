Easy 1-Minute Setup

No third-party VPN apps needed. Native OS settings only.

📱 Android Setup

  1. Go to phone Settings ➔ Connections ➔ More connection settings.
  2. Tap on Private DNS.
  3. Select Private DNS provider hostname.
  4. Paste your assigned DNS code (e.g. user123.dns.sohel.pp.ua) and tap Save.

🍎 iPhone / iPad Setup

  1. Download your personalized .mobileconfig profile from our portal.
  2. Open Settings ➔ Profile Downloaded.
  3. Tap Install and confirm with your Passcode.
  4. Your device is now securely connected via encrypted DNS!
