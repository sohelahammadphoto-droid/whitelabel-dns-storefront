Easy 1-Minute Setup

No third-party VPN apps needed. Native OS encrypted DNS settings only.

Android 9+

📱 Android Setup

  1. Open phone Settings ➔ Connections ➔ More connection settings.
  2. Tap on Private DNS.
  3. Select Private DNS provider hostname.
  4. Paste your assigned Private DNS hostname (received after activation) and tap Save.
iOS 14+

🍎 iPhone / iPad Setup

  1. Log in to your account and tap Download iOS Profile (.mobileconfig).
  2. Open Settings ➔ Profile Downloaded.
  3. Tap Install and confirm with your device Passcode.
  4. Encrypted DNS is instantly activated across Cellular & Wi-Fi!
Windows 11

💻 Windows 11 (DoH)

  1. Go to Settings ➔ Network & Internet ➔ Wi-Fi or Ethernet.
  2. Click Hardware Properties ➔ DNS server assignment ➔ Edit.
  3. Select Manual ➔ IPv4 ON, enter DNS IP, and select Encrypted only (DNS over HTTPS).
macOS 11+

🍏 macOS Setup

  1. Download the signed .mobileconfig profile from your user dashboard.
  2. Double-click the downloaded file to install in System Settings ➔ Profiles.
  3. Click Install to enable system-wide encrypted DNS.
