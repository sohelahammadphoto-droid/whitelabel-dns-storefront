# 🚀 Whitelabel Reseller Storefront Template (প্রাইভেট ডিএনএস রিসেলার ওয়েবসাইট)

একটি সম্পূর্ণ তৈরি, আল্ট্রা-মডার্ন ও ১০০% নিরাপদ **Whitelabel Private DNS Storefront Template**। 
যেকোনো রিসেলার মাত্র **২ মিনিটে সম্পূর্ণ ফ্রিতে Cloudflare Pages-এ ডিপ্লয় করে** নিজস্ব ব্র্যান্ডেড ওয়েবসাইট লাইভ করতে পারবেন!

> 💡 **নতুন আপডেট (100% Database Driven):** কোনো Cloudflare Environment Variables যুক্ত করার ঝামেলা নেই! আপনার এপিআই কি, পাসওয়ার্ড, হোয়াটসঅ্যাপ নাম্বার ও পেমেন্ট মেথড সবকিছু আপনার নিজস্ব **D1 Database**-এ সংরক্ষিত থাকবে এবং সরাসরি আপনার **ওয়েবসাইট অ্যাডমিন প্যানেল (`/admin.html`)** থেকেই পরিবর্তন করা যাবে!

---

## ✨ মূল ফিচারসমূহ (Features)

* 🎨 **প্রিমিয়াম SaaS ডিজাইন:** আল্ট্রা-মডার্ন ডার্ক থিম, গ্লাস মরফিজম, প্যাকেজ কার্ড এবং ১০০% মোবাইল রেসপন্সিভ।
* 🪄 **ইনস্ট্যান্ট ফার্স্ট-টাইম সেটআপ উইজার্ড:** সাইট ডিপ্লয় করার পর প্রথমবার `/admin.html`-এ গেলে উইজার্ড ওপেন হবে—সেখান থেকেই সরাসরি অ্যাডমিন পাসওয়ার্ড ও এপিআই কি সেট করা যায়।
* 🔒 **১০০% নিরাপদ API Proxy:** রিসেলারের `RESELLER_API_KEY` কখনোই ব্রাউজারে ফাঁস হবে না; আপনার নিজস্ব D1 ডাটাবেজে এনক্রিপ্টেড থাকবে।
* 💾 **সম্পূর্ণ আলাদা D1 ডাটাবেজ:** আপনার কাস্টমারদের নাম, ফোন নাম্বার এবং পেমেন্ট রেকর্ড আপনার নিজস্ব ক্লাউডফ্লেয়ার অ্যাকাউন্টে জমা থাকবে।
* ⚡ **১-ক্লিক অর্ডার ও ডিএনএস অ্যাপ্রুভাল:** কাস্টমার পেমেন্ট ট্রানজেকশন দিলে অ্যাডমিন প্যানেল থেকে ১ ক্লিকে মেইন এপিআই ব্যালেন্স কেটে কাস্টমারকে স্বয়ংক্রিয়ভাবে ডিএনএস পিন দেওয়া যায়।
* 🔍 **কাস্টমার সেলফ-সার্ভিস পোর্টাল:** ক্রেতারা ফোন নাম্বার বা পিন দিয়ে তাদের ডিএনএসের মেয়াদ ও ডিটেইলস চেক করতে পারে।
* 📱 **সম্পূর্ণ কন্ট্রোল অ্যাডমিন প্যানেল (`/admin.html`):** এপিআই কি পরিবর্তন, পাসওয়ার্ড পরিবর্তন, স্টোর নাম, হোয়াটসঅ্যাপ ও পেমেন্ট নাম্বার সব কিছু ১ ক্লিকে অ্যাডমিন থেকে আপডেট করা যায়।

## 🛠️ ২ মিনিটে ওয়েবসাইট ডিপ্লয় করার সহজ ৩টি স্টেপ (Deployment Guide)

### স্টেপ ১: রিপোজিটরি ফর্ক করুন (Fork Repo)
1. এই GitHub রিপোজিটরির উপরে ডানপাশে থাকা **Fork** বাটনে ক্লিক করে আপনার নিজস্ব GitHub অ্যাকাউন্টে কপি করে নিন।

---

### স্টেপ ২: ক্লাউডফ্লেয়ার D1 ডাটাবেজ তৈরি করুন (Create D1 Database)
1. আপনার [Cloudflare Dashboard](https://dash.cloudflare.com/)-এ লগইন করুন।
2. বাম পাশের মেনু থেকে **Storage & Databases** ➔ **D1 SQL Database**-এ ক্লিক করুন।
3. **Create Database** বাটনে ক্লিক করে নাম দিন: `store_db` এবং **Create** চাপুন।

---

### স্টেপ ৩: Cloudflare Pages-এ ডিপ্লয় করুন ও D1 বাইন্ড করুন
1. ক্লাউডফ্লেয়ার ড্যাশবোর্ড থেকে **Workers & Pages** ➔ **Create Application** ➔ **Pages** ➔ **Connect to Git** সিলেক্ট করুন।
2. আপনার GitHub অ্যাকাউন্ট থেকে ফর্ক করা রিপোজিটরিটি সিলেক্ট করুন।
3. সেটিংস অপশনে নিচের তথ্য দিন:
   * **Framework preset:** `None`
   * **Build output directory:** `public`
4. **Save and Deploy** বাটনে ক্লিক করুন।
5. ডিপ্লয়মেন্ট শেষ হলে প্রজেক্ট পেজ থেকে **Settings** ➔ **Functions**-এ ক্লিক করুন।
6. নিচে স্ক্রল করে **D1 Database Bindings** সেকশনে গিয়ে **Add binding** চাপুন:
   * **Variable name:** `DB` *(অবশ্যই বড় হাতের DB লিখবেন)*
   * **D1 database:** ড্রপডাউন থেকে আপনার তৈরি করা `store_db` সিলেক্ট করুন।
7. **Save** চাপুন।

---

## 🎉 স্টেপ ৪: সাইট চালু ও ইনস্ট্যান্ট সেটআপ (Initial Setup Wizard)
1. আপনার ডিপ্লয় হওয়া ওয়েবসাইটের লিঙ্কের শেষে `/admin.html` লিখে ব্রাউজারে ওপেন করুন (যেমন: `https://your-site.pages.dev/admin.html`)।
2. স্বয়ংক্রিয়ভাবে **Setup Wizard** চলে আসবে:
   * আপনার অ্যাডমিন লগইন পাসওয়ার্ড দিন।
   * আপনার **Reseller API Key** (`rsk_live_...`) পেস্ট করুন।
   * আপনার ওয়েবসাইটের নাম ও হোয়াটসঅ্যাপ নাম্বার দিন।
3. **"Save & Launch Admin Dashboard"** বাটনে চাপুন।

✨ **অভিনন্দন! আপনার নিজস্ব প্রাইভেট ডিএনএস ওয়েবসাইট ও অ্যাডমিন প্যানেল পুরোপুরি লাইভ ও রেডি!** 🚀

## 🌐 কাস্টম ডোমেইন যুক্ত করার নিয়ম (Custom Domain)
1. আপনার Pages প্রোজেক্টের **Custom Domains** ট্যাবে যান।
2. **Set up a custom domain** বাটনে ক্লিক করে আপনার নিজস্ব ডোমেইন (যেমন: `dns.yourbrand.com`) লিখে দিন।
3. ক্লাউডফ্লেয়ার নিজে থেকেই সম্পূর্ণ ফ্রিতে SSL সার্টিফিকেট সহ ডোমেইন কানেক্ট করে দেবে!
